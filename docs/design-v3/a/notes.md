# 방꾸미 디자인 v3 · A안 "커머스 클린" (2차 수정)

파일: `landing.html`(시작 화면) · `app.html`(작업 공간) · `tokens.css`(토큰 + 컴포넌트) · `iso-room.svg`(입체 그림, `gen-iso.mjs`로 만듦) · `shots/`(1366×768 캡처. 09·10은 1920×1080, 15·16은 1366×650)

목업에서 눌러 볼 수 있는 것: 카테고리 6개, 2D/3D 탭, 배치안 썸네일, 통로 스위치, 스타일 카드(평면도 색이 바뀜), [AI로 만들기](기다림 → 새 카드), 비용 줄 펼치기, 레일 맨 아래 **목업 상태**(기본 / 겹침 오류 / 빈 화면 / 예산 초과 / AI 쓰는 중 / 기본 설명). `app.html?state=empty`처럼 주소로도 열 수 있어요.

## 1. 심사 지적에 대한 답

| 지적 | 이렇게 고쳤어요 |
|---|---|
| 평면도가 작고 글자가 안 읽힘 | 예시 방을 가로로 긴 4.0×3.0m로 바꾸고, 떠 있는 것을 위·아래 얇은 줄과 오른쪽 기둥으로 몰았어요. 1366×768에서 방 폭 379px → **639px**, 1366×650에서도 511px이에요. 평면도 글자는 화면 12px 아래로 내려가지 않아요(JS가 `--k`를 계산) |
| 도구 막대가 평면도를 가림 | 캔버스 아래 가운데에 고정한 흰 막대로 옮기고, 단축키 3개를 그 안에 합쳤어요 |
| 통로 표시가 지저분함 | 빗금·점선을 빼고 옅은 애저 면(7%) 하나만 남겼어요. 60cm가 안 되는 틈은 비워 둬요 |
| 상태가 안 그려짐 | 겹침 오류, 빈 화면, 예산 초과를 화면으로 그렸어요(11~13번 캡처). 놓지 못한 가구 안내, AI 스타일 기다림과 만든 카드, 시세 범위·출처·찾는 중, DWG 방 고르기도 자리를 잡았어요 |
| 3D가 실제와 다름 | 6번에 three.js 색·빛 규칙을 적었어요. 보는 방향 버튼은 2D/3D 탭 옆으로 옮겼어요 |
| 스타일을 골라도 그대로 | 스타일 5색이 평면도 바닥·나무·패브릭·러그에 바로 입혀져요. 팔레트는 스타일 패널 맨 위와 캔버스 칩에 보여요 |
| 떠 있는 것이 많음 | 배치안 넘기기·범례·단축키 줄을 없앴어요. 열려 있는 카테고리의 칩은 숨겨서 같은 숫자가 두 번 나오지 않아요. 쇼핑 링크는 줄을 펼쳤을 때만 보여요 |
| 만화 같은 그림 | 스타일 카드를 색·마감재 무드보드 타일로 바꿨어요. 책은 3색 + 살구색 하나, 화분은 길쭉한 잎, 의자는 얇은 좌판으로 다시 그렸어요. 가구 썸네일은 칸을 꽉 채우는 정면 그림이에요 |
| 애저 하나 규칙 | 검은 면(도구 막대·토스트·예산 카드·2D 탭)을 모두 흰색으로 바꿨어요. 선택은 전부 옅은 애저 면 + 짙은 애저 글자예요. 옅은 면 위 글자는 #085BB5(5.9:1) |
| 첫인상 마감 | 위 막대에 "방꾸미" 글자를 넣고 [예시 불러오기]를 테두리 버튼으로 바꿨어요. 시작 화면은 높이 650px에서도 한 화면에 들어와요 |

| 리포트 | 색상 팔레트·마감재·분위기, AI 추천 설명(AI 생성 / 쓰는 중 / 기본 설명) | SketchUp 파일로 받기 / 열기 |

- **두 번 클릭 시연:** [예시 불러오기] → [배치 추천받기]는 위 막대에 항상 있어요. 추천받은 뒤에는 글자가 "다시 추천받기"로 바뀌어요.

- 레일은 위·아래 화살표 키로 옮겨 다닐 수 있고 `aria-controls`로 패널과 이어져 있어요.

## 5. 평면도 그리는 규칙

단위는 cm, 방 400×300이면 `viewBox="-38 -40 452 368"`(왼쪽 38, 위 40, 오른쪽 14, 아래 28 여백). 선 굵기는 `vector-effect: non-scaling-stroke`로 화면 px 고정이고, 글자는 `--k`(화면 1px = 몇 cm)를 곱해서 화면 12~13px로 맞춰요.

| 요소 | 규칙 |
|---|---|
| 바닥 | 스타일 벽색을 45% 섞은 흰색 + 50cm 격자(5% 선). 나무 무늬 없음 |
| 벽 | 두께 8cm, #3D4756. 방 전체에 옅은 그림자 하나 |
| 창문 | 벽을 끊고 흰 면 + 가는 선 2줄. 커튼은 창 양끝 물결선 |
| 현관 | 벽을 끊고 문짝(3.5cm) + 가는 실선 호 + 4% 부채꼴 |
| 치수선 | 방 밖 24cm, 회색 1px + 45° 끝 표시. 전체 폭·높이는 숫자만, 창문·현관 폭은 옆에 작게, 오른쪽 아래에 축척 막대와 "단위 cm" |
| 가구 면 | 고른 스타일 5색에서 만들어요. 나무 = `--c2` 66%, 옅은 나무(옷장) = 30%, 패브릭(이불·의자) = `--c3` 56%, 러그 = `--c4` 58% (나머지는 흰색을 섞음). 외곽선 #3A4557 1.2px, 안쪽 선 0.8px 50% |
| 가구 기호 | 침대: 틀·머리판·매트리스·베개·접은 이불 / 옷장: 봉 + 번갈아 기운 옷걸이 + 문 선 / 책장: 칸 + 대각선 / 책상: 모니터·키보드·마우스 + 의자 / 러그: 흰 안 테두리 / 무드등: 원 + 옅은 빛 / 화분: 잎 8장 |
| 이름표 | 가구 가운데 13px 굵게 + 치수 12px. 알약 배경 대신 가구 색 외곽(`paint-order: stroke`) |
| 통로 60cm | 옅은 애저 면 하나(7%), 모서리만 살짝 둥글게. 60cm가 안 되는 틈은 칠하지 않아요. 러그는 그 위에 그려요 |
| 거리 표시 | 가는 선 + 18px 알약(애저 = 고른 가구, 짙은 앰버 = 주의, 빨강 = 겹침) |

세로로 긴 방(예: 3×4m)은 높이에 맞춰져 방 폭이 약 380px로 줄어요. **예시 방을 4.0×3.0m로 바꾸는 것을 권해요.** 그대로 둘 거라면 세로 방일 때 `.view`의 위·아래 여백(60px·64px)을 14px로 줄이고 탭과 도구 막대를 평면도 왼쪽 빈 곳에 세로로 놓아요.

## 7. React로 옮기는 방법

1. **토큰:** `tokens.css`의 `:root`와 컴포넌트 클래스를 `src/theme.css`에 옮기고 옛 베이지·초록 변수를 지워요.
2. **뼈대(`App.jsx`):** `const [cat, setCat] = useState('layout')`. `.app`에 `data-cat={cat}`과 고른 스타일의 `--c1`~`--c5`를 인라인 스타일로 주고, `<TopBar>`, `<Rail>`, 패널 하나, `<Stage>`를 놓아요.
   - 방 → `RoomForm` + `DwgImport` / 스타일 → `StylePicker` / 가구 → `FurnitureInput` / 배치 → `ScorePanel` / 비용 → `CostTable` / 리포트 → 팔레트 + `AdvicePanel` + 내보내기 버튼
   - 기존 컴포넌트의 로직과 props는 그대로 두고 마크업의 클래스만 바꾸면 돼요.
3. **스타일 색:** 스타일 데이터의 5색을 벽·나무·패브릭·포인트·짙은 색 순서로 `--c1`~`--c5`에 넣어요. 평면도·썸네일·칩이 모두 이 변수를 읽어요.
4. **흐름:** [배치 추천받기]가 끝나면 `setCat('layout')` + 토스트. 배치가 없으면 빈 화면 카드와 "배치 추천받기" 글자를 보여요.
5. **캔버스(`Stage`):** 탭·스위치(`.stage-top`), 칩과 배치안(`.side`), 도구 막대(`.item-bar`), 토스트를 `.stage` 안에 절대 위치로 놓아요. 도구 막대는 고른 가구가 있을 때만 그려요.
6. **평면도(`Plan.jsx`, `symbols.jsx`):** 5번 표대로 다시 그려요. 상태는 `<g className="fx is-selected | is-warn | is-error">`로 주면 외곽선 색이 `--st`로 내려가요. 크기가 바뀔 때 `--k = max(viewBox폭 / 화면폭, viewBox높이 / 화면높이)`를 다시 넣어요.
7. **시작 화면:** `landing.html`을 `Landing.jsx`로 옮기고 저장된 작업이 없을 때만 보여 줘요. [예시로 보기]는 예시 불러오기 + 추천까지 한 번에 해요.
8. **빼야 할 것:** 레일 맨 아래 "목업 상태" 선택 상자와 `data-s` 속성은 목업 전용이에요.

- 오류 상태의 통로 면, 스타일을 바꿨을 때 리포트의 마감재·분위기 글은 목업에서 손으로 맞춘 값이에요.
- 3D 그림은 스타일을 바꿔도 색이 그대로예요(정적 SVG).
- `color-mix()`와 `zoom`을 써서 Edge·Chrome 기준이에요. 1700px 이상에서는 `.app`을 1.15배로 키워요.
- Edge 헤드리스로만 확인했어요. 실제 프로젝터, 화면 낭독기, Chrome은 확인하지 않았어요.
