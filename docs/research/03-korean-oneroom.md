# 03. 한국 원룸·자취방(5~10평) 가구 배치 조사

- 조사일: 2026-11-17, 웹 검색과 페이지 읽기로 조사했어요(약 10분).
- 대상: 5~10평(약 16~33㎡, 1평 ≈ 3.3㎡) 원룸. 방은 직사각형으로 봐요.
- 모든 수치는 **참고값**이에요. 법적·안전 기준이 아니에요.

## 0. 먼저 읽어 주세요 (조사의 한계)

- **오늘의집(ohou.se) 원문은 읽지 못했어요.** 페이지가 403(접근 거부)을 돌려줬어요. 오늘의집 관련 내용은 검색 결과에 보인 짧은 요약뿐이라 신뢰도를 "낮음"으로 적었어요.
- **유튜브 영상은 볼 수 없고, 자막·요약 글도 찾지 못했어요.** 유튜브 근거 규칙은 이 문서에 없어요.
- 한샘·일룸 같은 가구 회사의 공식 "배치 가이드"는 찾지 못했어요. 수치의 대부분은 개인 블로그·노트 글(tilnote.io, braindetox.kr, foxcg.com)에서 왔어요. 일부는 상품 홍보가 섞인 글이에요.
- 그래서 신뢰도는 이렇게 나눴어요.
  - **높음**: 제조사·판매사 공식 페이지(이케아 코리아, LG전자, 다나와 구매가이드)
  - **중간**: 서로 다른 글 2곳 이상이 비슷한 수치를 말함
  - **낮음**: 글 1곳만 말함, 또는 검색 요약에서만 확인(원문 미확인)
- 출처끼리 수치가 다르면 고르지 않고 **범위**로 적었어요.

## 4. 방 모양별 흔한 배치 (근거가 약해요)

방 모양별 배치를 수치로 설명한 믿을 만한 글은 찾지 못했어요. 아래는 경험담과 검색 요약이에요(모두 신뢰도 낮음).

- **세로로 긴 방(5.5평 사례)**: 긴 벽 한쪽에 침대를 세로로 붙이고, 맞은편 벽에 책상. (S — tilnote 글의 검색 요약)
- **가로로 넓은 방(6평 사례)**: 침대를 슈퍼싱글로 줄이고 벽에 가로로 붙이니 방 가운데에 설 자리가 생김. (T1, S)
- **길게 빠진 9평 직사각형**: 방 가운데에 수납장을 모아 구역을 둘로 나눔. (O1 검색 요약)
- **배치 순서**: 침대 자리 → 주 통로 → 책상(측면 채광) → 세로 수납 → 소품 순서. 큰 가구(침대·소파)부터 자리를 정함. (B1, M2 — 중간)
- **정사각형 방**: 따로 다룬 글을 찾지 못했어요. 규칙 없음.
