# 방꾸미 — AI 원룸 인테리어 플래너

가구를 사기 전에, 내 방에 맞는지 먼저 놓아 보는 웹앱이에요.
방 크기와 문·창문, 스타일, 예산, 갖고 싶은 가구를 적으면 겹치지 않고 통로가 남는 배치를 추천하고,
배치 점수 · 예상 비용 · 색상 팔레트 · AI 설명을 한 화면에서 보여 줘요.

## 실행

```bash
npm install        # 처음 한 번
npm start          # http://localhost:5174 (다른 포트를 쓰려면 npx vite --port <포트>)
npm test           # 배치 엔진 · 가구 해석 · 서버 · 화면 상태 테스트
npx vite build     # 배포용 묶음 만들기 (dist/)
```

- Node 26과 Edge에서 확인했어요(Chrome도 같은 엔진이라 돼요).
- AI 기능은 이 노트북에 로그인된 Claude Code(`claude` 명령)를 서버가 불러서 만들어요. 키가 브라우저로 나가지 않아요.
- `ADVICE_MODEL=sonnet npm start`처럼 모델을 바꿀 수 있어요(기본 haiku).

## 2분 시연 순서

**시작하기 전에:** 입력 패널의 **처음부터**를 한 번 눌러 주세요. 연습하면서 적어 둔 가격과 조사해 둔 웹 시세까지 모두 지워서, 늘 같은 화면(합계 857,000원, 가격은 모두 "예상")에서 시작해요.

1. **예시 불러오기** → **배치 추천받기**
   3m × 4m 방, 예산 100만원, 미니멀. 왼쪽에 예시 가구 4개가 보이고, 평면도에 가구가 놓이고, 오른쪽에 배치 점수가 나와요. 초록 점은 60cm 통로로 갈 수 있는 곳(참고값)이에요.
2. **책상을 끌어서 침대 위로**
   빨간 테두리와 "겹쳐요" 오류가 뜨고, 점수가 바로 떨어지면서 빨간 "고쳐 주세요"로 바뀌어요. 도구 막대의 **돌리기**나 `R` 키로 돌리고, 방향키로 5cm씩 옮겨요.
3. **배치안 넘기기**
   위쪽 `‹ 배치안 1 / N ›` 또는 오른쪽 작은 그림을 눌러 다른 배치안을 봐요.
4. **실제 상품에서 고르기** → **담기** → **배치 다시 추천받기**
   ④ 가구의 [실제 상품에서 고르기]를 눌러 "책상 1200"처럼 찾고 [담기]를 누른 뒤 창을 닫아요. 가구 목록에 "실제 상품" 줄이 생기고, 다시 추천받으면 그 상품의 실제 치수로 방에 놓여요.
   예상 비용에는 "다나와 최저가"(또는 "이케아 공식가") 표시와 [상품 페이지] 링크가 붙어요. 글로 적은 가구는 그 줄의 [실제 상품 찾기]로 크기가 비슷한 상품으로 바꿀 수 있어요.
5. **가격을 실제 가격으로 맞추기**
   오른쪽 **예상 비용**에서 [오늘의집] 버튼으로 실제 상품을 보고, 가격 칸에 그 가격을 적어요.
   합계와 남은 예산은 패널 아래에 붙어 있어서 적는 순간 바로 바뀌는 것이 보이고, 그 줄에 "직접 입력" 표시가 붙어요. ↺ 버튼을 누르면 자동 가격으로 돌아가요.
   잠시 기다리면 "웹 검색 시세"가 들어온 가구도 보여요(20~60초).
6. **AI 추천 설명**
   오른쪽 맨 아래. 기본 설명이 먼저 나오고 20초쯤 뒤 AI가 쓴 설명으로 바뀌어요.
   가구를 옮기거나 스타일을 바꾸면 기본 설명으로 돌아갔다가, 손을 멈추고 2~3초 뒤 AI 설명을 스스로 다시 받아 와요(다시 20초쯤).
7. **스타일 직접 입력**
   ② 스타일의 직접 입력 칸에 "제주 감성 우드 앤 화이트"처럼 적고 **AI로 만들기**. 평면도 · 3D · 팔레트 · 소품 · 가격이 함께 바뀌어요.
8. **3D 보기** 탭 → **SketchUp 내보내기**(파일로 받기 또는 SketchUp에서 바로 열기)
9. (선택) **DWG 불러오기** → 도면에서 방을 골라 **이 방으로 설정** → ① 방에서 **창문 추가** → 다시 **배치 추천받기**
   도면에서는 창문을 찾지 못해요. 창문을 넣지 않으면 채광은 따지지 않은 점수라고 표시돼요.

## 기능

| 기능 | 설명 |
|---|---|
| 방 입력 | 가로 · 세로 · 천장 높이, 문과 창문을 여러 개 넣고 뺄 수 있어요. 빈 칸이나 범위 밖 숫자는 가까운 값으로 맞춰요 |
| 스타일 | 프리셋 12종 + 직접 입력(프리셋 이름이면 바로, 아니면 AI가 5색 팔레트 · 마감재 · 소품을 만들어요) |
| 가구 직접 입력 | "슈퍼싱글 침대, 책상 1400, 옷장 2개"처럼 글로 적으면 바로 알아봐요. 카탈로그에 없는 가구는 AI가 치수 · 가격을 추정하고("AI 추정"), 그 전까지는 임시 크기("치수 확인")로 쓸 수 있어요. 이름 · 치수 · 가격을 줄마다 고칠 수 있어요 |
| 실제 상품에서 고르기 | 다나와에서 조사한 상품 1만여 개와 이케아 가구 26개에서 찾아 [담기]를 누르면 실제 치수와 가격으로 가구 목록에 들어가요(검색 · 분류 · "내 방에 들어가는 것만" · 정렬). 글로 적은 가구는 [실제 상품 찾기]로 크기가 비슷한 상품으로 바꿀 수 있어요. 담은 상품의 치수는 고칠 수 없고, 가구 글을 고쳐도 사라지지 않아요 |
| 배치 추천 | 벽 · 문 · 창문 · 통로를 따져 배치안을 여러 개 만들어요. 놓지 못한 가구는 따로 알려 줘요 |
| 2D 평면도 | 나무 바닥, 문 여는 자리, 창가 빛, 가구 그림. 끌어서 옮기기(5cm 단위), 방향키, `R` 돌리기, `Delete` 빼기, 통로 보기 |
| 3D 보기 | 같은 배치를 3D로(조감 · 위에서 · 눈높이). 3D 탭을 열 때만 three.js를 불러와요 |
| 배치 점수 · 검사 | 인테리어 원칙 7가지로 100점 만점 점수를 매기고, 겹침 · 문 막힘 · 통로 끊김을 알려 줘요. 끄는 동안에도 바로 바뀌어요 |
| 예상 비용 | 가구와 소품마다 가격 칸, 쇼핑몰 검색 링크(오늘의집 · 네이버쇼핑 · 쿠팡), 합계 · 예산 막대 · 초과 경고 |
| AI 추천 설명 | 서버가 배치를 다시 검사한 사실을 바탕으로 AI가 써요. AI가 안 되면 기본 설명이 나와요 |
| DWG 불러오기 | DWG · DXF 도면에서 방을 골라 크기와 문을 가져오고, 도면 선을 평면도 아래에 옅게 깔아요 |
| SketchUp 내보내기 | 방과 가구를 `.skp` 파일로 받거나 이 노트북의 SketchUp으로 바로 열어요 |
| 저장 | 입력 · 배치 · 직접 만든 스타일 · 직접 입력한 가격 · 조사한 웹 시세가 브라우저에 저장돼요. 입력 패널의 **처음부터**로 모두 지워요 |

## 가격은 어디서 오나요

가격은 네 가지가 있어요. 글로 적은 가구는 예상 → 웹 검색 시세 → 직접 입력 순서로, 실제 상품은 다나와 최저가 / 이케아 공식가 → 직접 입력 순서로 뒤쪽이 우선해요. 칸마다 어떤 가격인지 표시가 붙어요.

| 표시 | 뜻 |
|---|---|
| **예상** | 시연용 예상 가격이에요(카탈로그 값 × 스타일 배수). 실제 판매 가격이 아니에요 |
| **웹 검색 시세** | 배치를 추천받으면 AI가 웹 검색 결과에서 실제 판매 가격대를 한 번 조사해요. 범위와 출처 링크를 함께 보여 줘요. 못 찾은 것은 "예상" 그대로예요 |
| **다나와 최저가 / 이케아 공식가** | [실제 상품에서 고르기]로 담은 상품의 가격이에요. 다나와는 2026년 11월 17일에 조사한 최저가(배송비 제외, 가장 싼 옵션 기준), 이케아는 2026년 11월에 조사한 공식가예요. 스타일 배수를 곱하지 않고, 웹 검색 시세 조사에서도 빠져요. [상품 페이지] 링크가 함께 붙어요. 실제 가격과 다를 수 있어요 |
| **직접 입력** | 사용자가 가격 칸에 적은 값이에요. 다른 가격보다 우선하고, ↺로 되돌릴 수 있어요 |

- 웹 검색 시세가 예상 가격의 0.4배보다 싸거나 2.5배보다 비싸면(다른 물건을 읽었을 수 있어요) 합계에는 예상 가격을 쓰고, 웹 시세는 그 줄에 참고로만 보여 줘요. 맞는 가격이면 가격 칸에 직접 적으면 돼요. 이 배수는 참고값이에요.
- 합계는 왼쪽에 적어 둔 가구 전부와 소품을 세요. 평면도에 아직 없는 가구는 줄에 "배치 전", 자리를 못 찾은 가구는 "못 놓음"이라고 표시돼요.
- **예시 불러오기**는 직접 입력한 가격을 지우고, **처음부터**는 조사해 둔 웹 시세까지 모두 지워요.

**오늘의집은 링크로만 연결해요.** 오늘의집은 robots.txt와 약관으로 프로그램의 자동 수집을 막고 있어서, 앱이 상품 화면을 대신 읽어 오지 않아요.
대신 사용자가 링크로 들어가 직접 본 가격을 가격 칸에 적으면 합계가 바로 바뀌어요. 자세한 조사 내용은 `docs/shop-research.md`에 있어요.

## 알아 둘 점 (한계)

- **AI · DWG · SketchUp은 이 노트북의 프로그램을 써요.** AI는 로그인된 `claude` 명령, DWG 변환은 AutoCAD(accoreconsole), SketchUp 내보내기는 python과 SketchUp 2023 SDK가 있어야 해요.
  없는 PC에서는 그 버튼만 꺼지거나 기본값으로 대신하고, 평면도 · 점수 · 비용은 그대로 써요(DXF 파일은 AutoCAD 없이도 열려요).
- **AI는 기다려야 해요.** 설명 약 20초, 스타일 10~20초, 웹 검색 시세 20~60초. 기다리는 동안에도 화면은 계속 쓸 수 있어요.
- **가격은 참고용이에요.** "예상"은 시연용 값이고, "웹 검색 시세"도 AI가 검색 결과에서 읽은 값이라 틀릴 수 있어요. "다나와 최저가"와 "이케아 공식가"도 조사한 날의 값이라 실제 가격과 다를 수 있어요. 살 때는 쇼핑몰에서 직접 확인해 주세요.
- **통로 60cm와 배치 점수는 참고값이에요.** 법이나 안전 기준이 아니에요.
- **방은 네모난 방만 돼요.** ㄱ자 방은 감싸는 네모로 가져와요. DWG에서 창문은 자동으로 찾지 못해서 직접 넣어야 해요(안 넣으면 채광·창문 항목은 따지지 않고 만점으로 두고, 그렇게 표시해요).
- **배치 점수는 평면도에 놓인 가구만 봐요.** 겹치거나 문을 막는 오류가 있으면 점수와 상관없이 "고쳐 주세요"로, 못 놓은 가구가 있으면 "놓인 가구만 본 점수"로 표시해요.
- **가구는 한 번에 15개까지** 알아봐요. 실제 상품에서 담은 가구도 합쳐서 15개까지예요.
- **상품 자료는 2026년 11월 17일에 한 번 조사한 값이에요.** 상품 사진은 인터넷이 될 때만 보여요. 벽 선반처럼 바닥에 놓지 않는 상품은 빠져 있어요.
- 저장해 둔 상품 정보가 깨져 있으면 그 가구는 일반 가구로 남아요. 그 뒤에 가구 글을 고쳐 다시 알아보면 기본 치수의 새 가구로 바뀔 수 있어요.
- 배치안을 바꾸면 그 배치안에서 손으로 옮긴 위치는 처음 추천 상태로 돌아가요.
- SketchUp에서 바로 열 때 SketchUp이 알림 창을 먼저 띄우면 확인을 눌러야 파일이 열려요.
